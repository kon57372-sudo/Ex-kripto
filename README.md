# HAM Exchange

Android cryptocurrency exchange app (internal paper trading) with real market data from CoinGecko.

Build via GitHub Actions -> artifact HAM-Exchange.apk.

## Notes
- Internal balance starts at US$100,000,000,000 (paper, not withdrawable).
- Market data fetched live from CoinGecko (top 300 by market cap).
- No real exchange/blockchain execution; all trades are internal.
